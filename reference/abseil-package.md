# abseil: 'C++' Header Files and Compiled Library from 'Abseil'

Wraps the 'Abseil' 'C++' library for use by R packages. Original files
are from \<https://github.com/abseil/abseil-cpp\>. Patches are located
at \<https://github.com/doccstat/abseil-r/tree/main/local/patches\>.
